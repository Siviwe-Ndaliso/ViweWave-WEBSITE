# ViweWave K-pop Store 💖

An interactive e-commerce web platform for K-pop fans in South Africa, featuring dynamic shopping carts, lightboxes, forms validation, and SEO structures.

## Project Structure
* `index.html` - Home storefront page
* `productspage.html` - Product catalog layout
* `shoppage.html` - Active interactive shopping layout
* `shopping cart and checkout.html` - Cart manager and order checkout system
* `enquiry.html` - Dynamic task enquiry form
* `contact.html` - General message query form
* `robots.txt` & `sitemap.xml` - Search Engine Optimization (SEO) mapping

## Features Implemented (Part 3)
* **Dynamic Cart System:** Utilizes Web Storage API (LocalStorage) to persist items, increments item quantities, updates totals, and clears on completed checkout.
* **Form Validation:** Advanced client-side validation logic running on both message and enquiry portals with clear custom DOM error reporting.
* **Image Gallery Lightbox:** Implemented interactive JavaScript-driven modals to display high-resolution item banners gracefully upon click.
* **SEO Optimizations:** Configured semantic metadata, explicit image alternative descriptions, automated crawl configurations (`robots.txt`), and structured sitemaps.
