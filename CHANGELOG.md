# Changelog

All notable changes to the ViweWave Website project are documented below.

## [1.0.0] - 2026-06-19

### Added
- Created foundational core pages: `index.html`, `homepage.html`, `about.html`, and `productspage.html`.
- Added functional interaction pages: `shoppage.html`, `shopping cart and checkout.html`, and `events and news section.html`.
- Added new customer interaction and submission forms: `contact.html` and `enquiry.html`.
- Implemented client-side JavaScript search filter functionality in `script.js`.
- Configured search engine optimization (SEO) basics with `robots.txt` and `sitemap.xml`.

### Changed
- Updated global responsive grid design and layout structures inside `style.css`.
- Refactored JavaScript logic to handle custom e-commerce interface changes.

### Fixed
- Fixed deployment structure blocks and synchronized local directory configurations during Git staging.
